GPU Manager

Read-only monitoring

Monitor GPU memory, load and temperature. This tool does not close programs or release memory.

Resource history

Last 10 minutes while this screen is open · local session only

RAM is system-wide available memory, not only ComfyUI. VRAM and GPU readings include all processes; missing samples are not treated as zero.

How does GPU monitoring work?

VRAM is video memory occupied by all GPU programs. GPU utilization is activity rather than free memory. Metrics are estimates reported by the NVIDIA driver.

ORKILAB / COMFYUI ZONE

Discover ComfyUI in OrkiLab

ComfyUI is a node-based environment for building AI generation workflows. OrkiLab brings its models, nodes, workflows, generation and results into a guided workspace without replacing ComfyUI.

Generate and experiment

Work with images, video, audio and compatible 3D workflows according to the models and custom nodes installed on your ComfyUI server.

Organize your workflows

Import, search and inspect saved workflows; prepare complex visual graphs with the OrkiLab Bridge before submitting them.

Control and compare

Review parameters, follow execution, cancel OrkiLab jobs safely, inspect outputs and compare compatible LoRA strengths.

Monitor resources

Explore GPU use and optionally unload cached models after generation. ComfyUI must be running to use the connected tools.
