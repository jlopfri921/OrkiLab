## Other contributors

Contributors to OrkiLab are welcome and are recognized through Git history, issue and pull-request records, and this document as appropriate. GitHub's automatically generated **Contributors** graph is **not controlled by this document**. It depends on the authorship email recorded in Git commits, whether GitHub associates that email with an account, and the branch on which commits land.

**To ensure an individual contributor's GitHub profile can be associated with future commits**, that contributor should author commits from a Git client using a verified email address attached to their GitHub account. Avoid rewriting historical commits solely to change public contributor statistics.
