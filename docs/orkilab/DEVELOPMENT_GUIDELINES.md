# Development workflow

Keep main stable; use orkilab/* feature branches and PRs. Add upstream once: git remote add upstream https://github.com/AcademiaSD/AcademiaSD_LoRAlab-TrainerStudio.git. Check git remote -v, fetch upstream, merge deliberately in an integration branch and review conflicts. Never overwrite origin, reset --hard or automatically replace fork code. Stop training and back up local settings before updating. Updater uses current origin branch, refuses dirty tracked files or detached HEAD, and only merges fast-forward. A missing branch fails rather than falling back. Untracked files are not removed by Git's merge; review collisions. For source ZIP use a clone. Dependency update remains a separate subsequent installer stage; inspect changes first.

Run existing UI smoke: venv\\Scripts\\python tools\\smoke_test_ui.py (Linux venv/bin/python tools/smoke_test_ui.py). Test on a temporary clone, no model download; test changes against Windows and Linux. Use synthetic dataset fixtures and mock HTTP. Hardware matrix: RTX 3090 24 GB/64 GB RAM reference; lower-VRAM NVIDIA, Linux; AMD experimental inherited. Record exact CUDA, driver, torch and model versions. Never change ComfyUI environment. Use small commits; update version and changelog. For PR acceptance require code review, test results and explicit pending items.

Foundation RC: run `python -m unittest discover -s tests -v`. Updaters now update source only by default. `--deps` updates only the local venv; manually maintain intentional custom environments. Stop all jobs first.
