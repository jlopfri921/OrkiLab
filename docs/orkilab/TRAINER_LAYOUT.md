# Modern trainer layout

All 20 trainer pages (21 configured engines) now include the shared staged layout, including LTX 2.3, LTX 2.5, WAN 2.2, YuE2 and MiniMax H3 (image/video share a page). MiniMax has a dedicated RefMod stage; all existing controls and callbacks are preserved. Unrecognized sidebar panels cause a safe fallback to the original layout rather than conceal features. The common Basic mode hides only selected advanced groups, never changing values; video frame/audio settings, memory profiles, model selection, and other specialized controls remain available. Navigation strings update through the shared eight-language catalogues. Classic fallback is temporary until runtime validation completes. The controller source and engine assets are synchronized. SDXL was reported working locally; the other engines still require browser and real training tests.
